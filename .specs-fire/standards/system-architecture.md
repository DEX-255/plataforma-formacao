## Forma do sistema

```
navegador  ──►  Next.js (App Router, Vercel)  ──►  Supabase (Postgres + RLS)
                        │
                        └── componentes de servidor por padrão (D-02)
```

**Duas camadas de privacidade, não uma.** A renderização no servidor impede que dado
proibido saia; a RLS e a view `feedback_visivel` impedem que ele seja lido mesmo se
sair. As duas erram por motivos diferentes — é por isso que ambas existem.

## Estrutura de pastas

```
app/          rotas: (publico)/ e (app)/
componentes/  ui/, feedback/, grafico/
dominio/      regras.ts, frameworks.ts, tipos.ts
lib/          supabase/ (cliente de servidor e de navegador), auth.ts
supabase/     migrations/, politicas/
documento/    gerador do documento final
```

## Três invariantes de estrutura

**`dominio/regras.ts` é a única casa das regras de negócio.** Nenhum componente decide
sozinho se um feedback pode ser editado. A tela pergunta, a regra responde. É o que
impede a mesma regra de existir em três lugares com três comportamentos.

**`dominio/frameworks.ts` é dado, não código espalhado.** Eixos, perguntas-âncora e
descritores da rubrica vivem numa estrutura declarativa. Acrescentar o framework de
Gestão Ágil ⏳ é acrescentar uma entrada — nenhuma tela muda. `eixo` é `text` no banco,
não `enum`, exatamente para isso.

**Dois clientes Supabase, e nunca o de navegador para dado sensível.** Toda leitura que
envolve bloco interno ou dado de turma acontece no servidor. A separação está na
estrutura de pastas, não na disciplina de quem escreve a tela.

## O que o esquema carrega sozinho

Regras que o banco garante sem depender de código:

- `check (length(btrim(sugestao)) > 0)` → `RN-01`
- `check (nao_observado = (nota is null))` → `RN-07`
- `unique (encontro_id, participacao_id, mentor_id, eixo)` → um registro por mentor por
  pessoa por encontro; observar de novo edita, não empilha
- Ausência de qualquer coluna ligando `mensagem_anonima` a `participacao` → `RN-08`
- Ausência de coluna de horário em `mensagem_enviada` → `RN-10`
- Nenhuma exclusão em cascata em lugar nenhum → `RN-18`
